# Logo MAINN Media

Các file trong thư mục này lấy từ logo gốc MAINN Media (bản PNG nền trong suốt):

| File | Dùng ở đâu |
|---|---|
| `logo.png` | Logo đầy đủ ở đầu trang (cao 144px, hiển thị cao 44px) |
| `icon.png` | Biểu tượng tab trình duyệt (chữ M, nền trong suốt) |
| `apple-touch-icon.png` | Biểu tượng khi lưu web ra màn hình iPhone (chữ M, nền trắng) |
| `og-image.png` | Ảnh hiện khi chia sẻ link qua Zalo/Facebook (1200×630, nền trắng) |

Muốn thay logo: tải file mới lên, **giữ nguyên tên file**. Màu giao diện nằm ở đầu phần `<style>` trong `index.html`.
